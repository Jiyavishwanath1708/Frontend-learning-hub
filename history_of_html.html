History of HTML Versions

HTML 1.0 (1991)

The first version of HTML, used to create basic web pages.

HTML 2.0 (1995)

The first official HTML standard, introducing basic web page features.

HTML 3.2 (1997)

Introduced features such as tables, scripting, and improved page formatting.

HTML 4.0 (1997)

Improved support for stylesheets, scripts, and multimedia.

HTML 4.01 (1999)

An improved version of HTML 4.0 with corrections and refinements.

XHTML 1.0 (2000)

Introduced stricter rules for writing HTML using XML syntax.

HTML5 (2014)

Added semantic elements, audio, video, and canvas support.

HTML Living Standard (Ongoing)

HTML is continuously maintained and updated by WHATWG.
